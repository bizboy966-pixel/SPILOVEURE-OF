## Root cause
`frontend/src/components/GlobalFonts.tsx` contains a **duplicated leftover block**. The `injectWebFonts()` template literal legitimately closes at line 99 (`` `; ``) and the function closes at line 101 (`}`). Lines 102–104 are a stray duplicate of that same closing block:

```
 99   `;
100   document.head.appendChild(style);
101 }
102   `;                                  <-- stray backtick opens a NEW template literal
103   document.head.appendChild(style);
104 }
```

The backtick on line 102 opens a second template literal that is never closed → "Unterminated template (102:3)".

## Fix (verified in eph sandbox)
Delete the duplicate block — lines **102, 103, 104**:
```
  `;
  document.head.appendChild(style);
}
```
After deletion, line 101 `}` (end of `injectWebFonts`) is immediately followed by the blank line and `export function GlobalFonts() {`.
