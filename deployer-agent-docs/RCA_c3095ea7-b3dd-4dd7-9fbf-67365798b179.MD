In `frontend/src/components/ChatBubble.tsx`, inside the chat `<Modal>` the JSX tree is:

- L343 `<Modal>`
- L344 `<View style={[styles.backdrop...]}>`
- L345 `<KeyboardAvoidingView ...>`
- **L350 `<View style={styles.panel}>`  ← opened, never closed**
- L351 `<View style={styles.header}>` … (header, ScrollView, preview/err/reply blocks, composer — all internally balanced)
- L538 `</View>`  (closes the composer `<View>` from L492)
- L539 `</KeyboardAvoidingView>`
- L540 `</View>`  (closes the backdrop `<View>` from L344)
- L541 `</Modal>`

The `<View style={styles.panel}>` opened at line 350 has **no matching `</View>`**. The parser reaches `</KeyboardAvoidingView>` at 539 while the `panel` View is still open, so it reports "Expected corresponding JSX closing tag for `<View>`". A stack-based tag balance over the whole `<Modal>` subtree confirmed exactly one surplus open `<View>` (the panel).
