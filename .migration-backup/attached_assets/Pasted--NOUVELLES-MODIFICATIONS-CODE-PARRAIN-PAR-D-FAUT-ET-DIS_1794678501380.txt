# NOUVELLES MODIFICATIONS : CODE PARRAIN PAR DÉFAUT ET DISTRIBUTION OFFICIELLE DE L'APPLICATION ANDROID SPILOVEURE

Ces modifications doivent être intégrées à la plateforme existante sans perturber les fonctionnalités déjà opérationnelles.

# PARTIE 1 : MODIFICATION DU FONCTIONNEMENT DU CODE PARRAIN

## 1. OBJECTIF

Je souhaite conserver intégralement le système de parrainage actuel de SPILOVEURE, avec une seule modification : le code parrain ne doit plus être obligatoirement fourni par un lien d'inscription.

Lorsqu'un utilisateur arrive sur la plateforme sans code parrain, le système doit automatiquement utiliser le code parrain de l'administrateur principal.

## 2. NOUVELLE LOGIQUE

### Cas A : inscription avec un lien contenant un code parrain

Si un utilisateur arrive sur SPILOVEURE à partir d'un lien d'inscription contenant un code parrain :

- Récupérer automatiquement le code parrain présent dans le lien.
- Associer ce code au nouvel utilisateur.
- Conserver le fonctionnement actuel du système de parrainage.
- Ne pas remplacer ce code par celui de l'administrateur.

Le code parrain transmis par le lien doit rester prioritaire.

### Cas B : inscription sans code parrain

Si un utilisateur arrive sur la plateforme sans utiliser de lien contenant un code parrain :

- Le système doit automatiquement récupérer le code parrain officiel de l'administrateur principal.
- Ce code doit être renseigné par défaut dans le champ correspondant.
- L'utilisateur doit être automatiquement rattaché à l'administrateur principal selon les règles actuelles du système.

Il ne doit plus être possible de bloquer une inscription simplement parce qu'aucun code parrain n'a été transmis dans le lien.

### Cas C : champ code parrain sur la page d'activation

Le champ du code parrain peut rester visible sur la page d'activation.

Cependant :

- Conserver son fonctionnement actuel.
- Préremplir automatiquement le code correspondant à l'utilisateur.
- Conserver le code transmis par le lien lorsqu'il existe.
- Utiliser le code de l'administrateur uniquement lorsqu'aucun code parrain valide n'a été transmis.

## 3. CONSERVATION DES RÈGLES EXISTANTES

Ne modifie pas :
- Le fonctionnement des liens de parrainage.
- L'attribution des filleuls.
- Les relations entre parrains et filleuls.
- La matrice binaire.
- Le système de spillover.
- Les commissions.
- Les niveaux.
- Les règles de validation existantes.

La modification concerne uniquement la valeur par défaut du code parrain lorsqu'aucun code n'est fourni.

Le code parrain de l'administrateur doit être récupéré depuis la configuration officielle du système, et non inscrit en dur dans le code source.

Éviter également toute possibilité de modifier frauduleusement le parrain après l'attribution initiale.

# PARTIE 2 : APPLICATION ANDROID OFFICIELLE SPILOVEURE AU FORMAT APK

## 1. OBJECTIF PRINCIPAL

Je souhaite que SPILOVEURE dispose de sa propre application Android téléchargeable directement depuis Internet, même si elle n'est pas encore publiée sur Google Play Store.

L'objectif est de permettre aux utilisateurs de rechercher SPILOVEURE sur Google ou depuis leur navigateur et de trouver une page officielle proposant notamment :

- Accéder à SPILOVEURE.
- Se connecter.
- Commencer une inscription.
- Télécharger l'application Android officielle au format APK.

Je veux une véritable application Android installable, et non un simple raccourci vers le site Internet.

## 2. PAGE OFFICIELLE DE TÉLÉCHARGEMENT

Créer une page officielle dédiée au téléchargement de l'application.

Cette page doit présenter :

- Le logo officiel de SPILOVEURE.
- Le nom de l'application.
- Une courte présentation.
- Un bouton « Télécharger l'application Android ».
- Un bouton « Accéder à la plateforme ».
- Les informations relatives à la version disponible.
- La taille du fichier.
- La date de publication de la version.

La page doit être responsive, professionnelle et optimisée pour les moteurs de recherche afin que les utilisateurs puissent retrouver facilement la page officielle lorsqu'ils recherchent SPILOVEURE sur Internet.

Prévoir également des métadonnées SEO, un sitemap et les informations nécessaires à l'indexation de cette page.

## 3. CRÉATION DU VÉRITABLE FICHIER APK

Je veux un véritable fichier APK Android produit à partir d'un projet d'application Android correctement construit.

Il ne faut pas simplement renommer un fichier ou transformer le lien du site en fichier APK.

L'application doit disposer :

- De son propre identifiant de package Android.
- De son nom officiel SPILOVEURE.
- De son icône officielle.
- De sa signature numérique.
- De ses permissions nécessaires.
- De sa configuration Android.
- De son système de connexion à la plateforme.
- De ses paramètres de sécurité.

L'application doit pouvoir être installée sur les appareils Android compatibles et communiquer correctement avec les services existants de SPILOVEURE.

## 4. FONCTIONNEMENT DE L'APPLICATION

L'application Android doit offrir une expérience cohérente avec la plateforme Web.

Elle doit permettre :

- L'inscription des utilisateurs.
- La connexion.
- L'accès au tableau de bord après activation et authentification.
- L'utilisation de SPILOVEURE CHAT.
- L'accès aux fonctionnalités disponibles.
- La réception des notifications.
- L'utilisation des services compatibles avec Android.

Conserver les mêmes comptes utilisateurs et les mêmes données que sur la version Web.

Un utilisateur ne doit pas avoir besoin de créer un deuxième compte pour utiliser l'application.

L'application doit également respecter la nouvelle procédure d'inscription, de vérification de l'e-mail et de gestion des sessions définie précédemment.

## 5. SÉCURITÉ DU FICHIER APK ET PROBLÈME D'INSTALLATION

Il existe actuellement un problème important à prendre en considération : certains fichiers APK téléchargés directement depuis Internet affichent des avertissements Android indiquant que le fichier peut être dangereux.

Je souhaite que ce problème soit étudié et corrigé autant que techniquement possible.

Pour cela :

- Générer un APK depuis une chaîne de compilation fiable.
- Utiliser une signature numérique valide.
- Conserver la même clé de signature pour les futures versions.
- Vérifier l'intégrité du fichier.
- Analyser le fichier avec des outils de sécurité.
- Éviter les bibliothèques et dépendances suspectes.
- Limiter les permissions aux besoins réels de l'application.
- Vérifier la compatibilité avec les protections Android et Google Play Protect.
- Publier le fichier uniquement depuis le domaine officiel de SPILOVEURE.

Le fichier proposé au téléchargement doit être le véritable APK signé de production, et non une version de test ou un fichier modifié manuellement.

**Important :** ne cherche pas à contourner Google Play Protect ni à désactiver les protections Android. L'objectif est de produire une application propre, correctement signée et vérifiée. Certains avertissements peuvent néanmoins subsister pour une application installée en dehors du Play Store ; il ne faut pas promettre leur disparition sans vérification réelle.

## 6. DISTRIBUTION ET HÉBERGEMENT

Prévoir un système permettant de :

- Héberger l'APK sur le domaine officiel.
- Télécharger le fichier directement depuis la page officielle.
- Vérifier que le fichier téléchargé n'est pas corrompu.
- Afficher les informations de version.
- Conserver les versions publiées.
- Contrôler l'intégrité du fichier à l'aide d'une empreinte cryptographique.
- Sécuriser l'accès au fichier de téléchargement.

Le lien de téléchargement doit toujours pointer vers la dernière version stable publiée, sans supprimer les possibilités de récupération des versions précédentes.

## 7. TESTS OBLIGATOIRES

Avant la publication :

- Installer l'APK sur plusieurs appareils Android compatibles.
- Tester l'ouverture et la navigation.
- Tester l'inscription et la connexion.
- Tester le paiement et la confirmation d'activation.
- Tester le Chat.
- Tester les notifications.
- Tester les différentes fonctionnalités de la plateforme.
- Vérifier la signature numérique.
- Vérifier l'intégrité du fichier.
- Effectuer des analyses de sécurité.
- Vérifier les performances et la stabilité.

Ne publie pas une application qui n'a pas été testée sur de véritables appareils Android.

# PARTIE 3 : PROTECTION DE L'EXISTANT

Ces deux modifications doivent être ajoutées sans modifier la finalité de SPILOVEURE.

Il est strictement interdit de :
- Supprimer des fonctionnalités existantes.
- Modifier le fonctionnement des paiements.
- Modifier les règles de commissions.
- Modifier le fonctionnement de la matrice.
- Modifier les comptes utilisateurs.
- Remplacer les systèmes déjà opérationnels.
- Perturber les intégrations existantes.

Avant de commencer, analyser l'architecture actuelle, identifier les dépendances et présenter le plan d'intégration.

Effectuer ensuite les tests de non-régression.

# INSTRUCTION FINALE

Je demande deux ajouts précis :

1. Rendre le code parrain facultatif dans le lien d'inscription, avec attribution automatique du code parrain de l'administrateur principal lorsqu'aucun code n'est fourni.
2. Créer une véritable application Android SPILOVEURE, avec son fichier APK officiel signé, téléchargeable et installable directement depuis notre site Internet.

**Ne transforme pas ces demandes en refonte générale. Ajoute uniquement ces fonctionnalités et préserve intégralement les systèmes existants.**
